# Fiqh Mastery Kit KSSM

Bahan pembelajaran digital Bidang Fiqah Pendidikan Islam KSSM Tingkatan 4 dan 5.
Semua isi diambil daripada Buku Teks Pendidikan Islam KSSM Tingkatan 4 dan Tingkatan 5,
dan dipadankan dengan corak Soalan 3 Set Soalan Percubaan SPM 2026.

## Kandungan

Setiap modul mempunyai enam tab:

1. **Analisis Master**: peta konsep, istilah, hukum, rukun dan syarat, perbezaan istilah, carta alir, soalan situasi, dalil dan hikmah
2. **Slaid**: 18–19 slaid pembelajaran
3. **Lembaran Kerja**: 5 tahap (Kenali, Fahami, Bezakan, Aplikasi, KBAT) dengan skema jawapan
4. **Game Zone**: 10 permainan (Matching, Sorting, Escape Room, Mystery Box, Detective, Wheel, True/False, Champion, Memory, Final Boss)
5. **Latihan SPM**: satu set Soalan 3 format percubaan dengan skema, teknik dan kesalahan lazim, serta 12 soalan objektif
6. **Diagnostik**: ujian pra dan pasca (5 aspek), analisis kesalahan, aktiviti pemulihan dan pengayaan

## Cara membuka

Buka `index.html` dalam pelayar. Tiada pemasangan diperlukan. Fon dimuatkan daripada Google Fonts.

## Menerbitkan di GitHub Pages

1. Cipta repositori baharu di github.com (contohnya `fiqh-mastery-kit`).
2. Dalam folder ini, jalankan:
   ```bash
   git remote add origin https://github.com/NAMA-ANDA/fiqh-mastery-kit.git
   git push -u origin main
   ```
3. Di GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
4. Laman akan tersedia di `https://NAMA-ANDA.github.io/fiqh-mastery-kit/` dalam beberapa minit.

## Nota

- Soalan latihan ialah rekaan guru mengikut format Kertas 1223/1. Ia bukan soalan sebenar SPM.
- Perkara di luar buku teks ditanda **Tambahan** atau **Prinsip umum fiqh**.
- Modul Jenayah dalam Islam disediakan untuk pembelajaran akademik. Pelaksanaan hukuman adalah di bawah pihak berkuasa dan mahkamah.
- Isi diringkaskan daripada buku teks KPM. Pertimbangkan hak cipta sebelum menjadikan repositori ini awam.
