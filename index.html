Analisis Soalan 3 · Percubaan SPM 2026

Apa yang Soalan 3 benar-benar uji

Soalan 3 Kertas 1223/1 ialah soalan Bidang Fiqah. Setiap set mengambil 2 hingga 3 tajuk, lazimnya satu dari Tingkatan 4 dan satu dari Tingkatan 5. Bilangan di bawah ialah berapa set (daripada 13) yang menyoal tajuk itu.

2MARKAH
(i) Nyatakan / Apakah maksudDefinisi buku teks, satu jenis, hukum. Jawapan mesti tepat kata kunci.
2MARKAH
(ii) Senaraikan / Jelaskan duaDua rukun, dua syarat, dua jenis, dua hikmah. 1 markah satu isi.
2MARKAH
(iii) Situasi / gambar / akhbarTentukan hukum + alasan, atau tindakan yang sepatutnya. Kenal pasti isu Fiqh dahulu.
4KBAT
(iv) Huraikan / Ramalkan / Cadangkan / Kemukakan hujahDua isi berhuraian (isi + huraian + contoh). Stimulus: infografik perceraian, skim cepat kaya, penipuan pakej umrah, nikah sindiket, status halal.
Gandingan paling kerapHaji atau Sembelihan (T4) bersama Talak dan isu perkahwinan (T5). 11 daripada 13 set mengikut corak ini.
Rukun dan syarat ialah markah mudahSyarat sah sembelihan, rukun akad, syarat rujuk, jenis miqat, wajib haji: semuanya soalan (ii) 2 markah.
Hukum taklifi bertukar ikut keadaanHukum talak (wajib, sunat, makruh, haram) muncul dalam 3 set sebagai soalan situasi. Murid mesti hafal syarat setiap hukum.
Belum disoal dalam set iniKorban dan Akikah, Solat Dhuha, Istikharah, Perkahwinan (P12), Faraid dan Jenayah. Masih dalam sukatan, jadi jangan diabaikan.
Set (penerbit)Tajuk yang disoalContoh soalan KBAT 4 markah

Dua set tidak memaparkan nama penerbit pada halaman yang diimbas, jadi dilabel “tidak dinyatakan”. Set Melaka tidak dapat dibaca daripada imbasan. Ini analisis set percubaan negeri, bukan soalan sebenar SPM.
